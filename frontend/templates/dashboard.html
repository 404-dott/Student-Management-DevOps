Multi-Tier DevOps Architecture
Tier 1: Frontend
Nginx Web Server

Serves static assets, routes single page views, and reverse proxies /api/* to Flask backend container.

Tier 2: Backend
Python Flask REST API

Handles authentication, database queries, business rules, CORS, and exposed health probe endpoints.

Tier 3: Database
MySQL 8.0 Engine

Persistent named volume storage with healthcheck queries and initial bootstrap data via init.sql.

CI/CD Pipeline Stages (Jenkinsfile)
  1. Git Checkout: Pulls latest code from GitHub.
  2. Lint & Unit Test: Runs pytest test cases in isolated test virtual environment.
  3. Docker Build: Builds production images with tags.
  4. Docker Compose Smoke Test: Boots test container network, verifies /api/health.
  5. Push to Docker Hub / Registry: Pushes latest images securely.
  6. Deploy to AWS / Production: Pulls and restarts live containers.
