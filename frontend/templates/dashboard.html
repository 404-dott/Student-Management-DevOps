Multi-Tier DevOps & CI/CD Pipeline
Frontend
Nginx Reverse Proxy

Serves static assets, routes UI templates, and handles reverse-proxying of /api/*.

Backend
Python Flask REST API

Production WSGI Gunicorn server managing authentication, CRUD, attendance tracking and health probes.

Database
MySQL 8.0 Engine

Persistent storage volume (mysql_data) with foreign key cascades, healthchecks and initialization SQL.
